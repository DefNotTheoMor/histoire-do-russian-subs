# Русские субтитры к «Histoire d'O» (1975)

Любительский перевод и полная пересборка субтитров к фильму Жюста Жакена по роману Полин Реаж.
Перевод сверялся с оригинальной французской дорожкой, а не с английским подстрочником.

> Эти субтитры предназначены для использования с легально приобретённой копией фильма. Совместимость проверена на издании 2007 года; MD5 видеодорожки тестового экземпляра указан в метаданных файла субтитров. Ориентировочный размер исходного файла – 13 ГБ.

Почему файл устроен именно так — в [`docs/razbor.md`](docs/razbor.md).

---

## Файл

`История О (1975).rus.ass` — главный и единственный артефакт репозитория.

## Шрифты

Файл использует **PT Serif** (Regular и Italic) и **Forum**.
Оба для просмотра должны вшиваться в контейнер вложениями.

## Метрики

Считаются скриптом `tools/check_subs.py`.

## Оформление документации

Markdown приведён к единому виду через [rumdl](https://github.com/rvben/rumdl); конфиг — `.rumdl.toml` в корне, он версионируется намеренно.
